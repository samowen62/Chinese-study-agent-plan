HSK 4 · 时间副词辨析：刚／刚才／原来／本来／差点／从来

语法点 L4 时间副词 group（CL02b） 话题 讲述昨天的经历 用时 约 13 分钟
学习目标：能区分三组最容易混的时间词 —— 刚/刚才（副词 vs 时间名词）、原来/本来（恍然大悟 vs 原计划）、差点/从来（险些 vs 从不）—— 并在讲故事时用对它们。

A 模式感知 Pattern warm-up

我刚到，你们聊什么呢？／刚才的事别提了。
刚 = 副词，紧跟动词
刚才 = 时间名词，可作定语：刚才的事。✗刚的事
啊，原来是你！／我本来想早睡。
原来 = 恍然大悟 / 起初的状态
本来 = 原来的计划（后来改变了）：本来想…后来…
我差点迟到。／他从来不迟到。
差点 = almost（事情没发生）
从来（不/没）= 从过去到现在一直

B 语法操练 Grammar drills

B1 选词填空：（　）的事就别提了，我们看现在。

B ✔ Only the time noun 刚才 can modify a noun (刚才的事). 刚 is an adverb — it must sit before a verb: 刚发生的事 is possible in speech, but in the slot before 的 with "the matter a moment ago", 刚才 is the standard answer; C/D mean "original/originally".

B2 哪个句子是对的？

C ✔ 刚 = adverb glued before the verb phrase 回国; no 了 of its own (A), no scrambling (B/D).

B3 他今天没来上课。后来你知道他生病了，还以为他偷懒呢。你说：

A ✔ 原来 = sudden realization ("so THAT's it"). 本来 is about a prior plan that changed — no realization flavor.

B4 选词填空：我（　）打算坐高铁去，但是票卖完了，只好开车。

B ✔ Prior plan + change = 本来……但是……. (原来 would suggest you only now found out about your own plan — odd.)

B5 选词填空：我（　）不喝咖啡，喝了晚上就睡不着。

A ✔ Habit from past to now → 从来＋不. 差点 = almost (one near-miss), 刚 = just now, 本来 = original plan.

B6 找错误：我从来了没见过这么美的景色。

B ✔ Fix: 我从来没见过……. 从来 never takes 了 — it's about an unbroken state up to now.

B7 排列顺序：

我们本来想坐飞机，可是太贵了。 本来 right after subject, before the planned action; the 可是-clause explains the change.

C 听力模拟 Listening simulation

Read aloud twice, then answer.

女:你昨天怎么没来参加聚会？
男:说来话长。我本来打算六点出发，可是公司临时有事，我不得不加班。
女:那也太晚了！
男:是啊。等我忙完，差一点儿赶不上末班车，幸亏跑得快！
女:你从来都是这么忙，应该早点儿跟老板说。
男:其实我原来想换个(新)工作，现在还没决定。
女:换工作？你刚才不是说工作挺好吗？
男:唉，好是好，就是太忙了。

C1 男的昨天为什么没来聚会？

A ✔ 本来打算六点出发 → 不得不加班 — the plan changed, and 不得不 (review from ws-003!) forced it.

C2 "差一点儿赶不上末班车"的意思是：

C ✔ 差点儿赶不上 = almost didn't catch it — but he DID (幸亏跑得快). 差点 always describes the thing that didn't happen.

C3 判断：男的一定要换工作。（√ / ×）

× ✔ 原来想换 — an earlier thought; 现在还没决定.

D 考试题型 Exam-style · 选词填空

1. 你去哪儿了？我到处找你。

2. 我想学游泳，后来觉得太贵就没学。

3. 他不吃肉，只吃鱼和青菜。

4.是你啊！我都没听出来你的声音。

1-A 刚才 · 2-C 本来 · 3-F 从来 · 4-D 原来（B 刚、E 差点 不用）
1. Question about the recent past → time noun 刚才. 2. Changed plan → 本来…后来. 3. Standing habit → 从来不. 4. Realization → 原来是你！

E 自由产出 Free production

E1 用"本来……（后来）……"写一件你改变了计划的事。

Model: 我本来想学钢琴，后来工作太忙就放弃了。 The 后来-clause should show what changed.

E2 用"差点"讲一次你的惊险经历（差一点儿发生的坏事）。

Model: 昨天路上有冰，我差点摔倒。 Check: the scary thing did NOT actually happen. If it happened, don't use 差点!

E3 用"原来"表达一次恍然大悟（"原来是…"）。

Model: 啊，原来这家店是你叔叔开的！怪不得每次都送我们水果。 Pattern: 原来＋真相＋（怪不得…）— the discovery pairs naturally with 怪不得.

F 温故知新 Review

F1 用"一天比一天"描述天气。from hsk4-ws-004 · 一天比一天

Model: 春天到了，天气一天比一天暖和了。

F2 用"再也不"写一个决心。from hsk4-ws-004 · 再也不

Model: 我再也不考试前才复习了。

F3 用"只好"完成：所有商店都关门了，我（　）。from hsk4-ws-003 · 只好

Model: 只好回家 / 只好饿着肚子睡觉.
