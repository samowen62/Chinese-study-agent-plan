# Level Guide (HSK 1–6)

Per-level profiles for worksheet generation. Exam structures are taken from the provided
past papers in `hsk1\`…`hsk6\` (note: those papers predate the 2025-11 syllabus; treat them
as the question-format reference per Sam's instruction, while ALL content — vocab, grammar,
topics — comes from the new syllabus PDF).

## Vocabulary boundaries (verified against the 词汇大纲 list)

The 词汇大纲 is ONE cumulative, pinyin-ordered list. Each word is tagged with its level.
Boundaries of each level's NEW words:

| Level | New words | Cumulative total | 词汇大纲 PDF pages |
|---|---|---|---|
| HSK 1 | #1–300 (300) | 300 | 77–84 |
| HSK 2 | #301–551 (251) | 551 | 84–89 |
| HSK 3 | #552–1000 (449) | 1000 | 89–102 |
| HSK 4 | #1001–2000 (1000) | 2000 | 102–127 |
| HSK 5 | #2001–3600 (1600) | 3600 | 127–167 |
| HSK 6 | #3601–5400 (1800) | 5400 | 167–212 |

Words tagged like `3（6）` mean the word enters at L3 (in one POS/use) and gains more
POS/uses at L6 — it is usable from its first-listed level. **Vocabulary policy**: worksheets
at level L use cumulative words #1 through L's boundary; up to ~5% of content words may
exceed, each glossed in the answer key.

## HSK 1

**Exam structure (past paper H10901)**: 听力 20题 (P1 picture true/false, P2 listen-pick
picture A–F, P3 dialogue-match, P4 mini-passage MCQ) · 阅读 20题 (P1 word↔picture true/false,
P2 sentence↔picture match, P3 Q–A matching, P4 word-bank fill 选词填空) · ~40 min.

**Grammar spine**: see `references/03-grammar-inventory.md` appendix §HSK 1 (是/有 sentences, basic SVO, 了1/了2,
在/正在, 吗/吧/呢 questions, measure words, numbers/time).

**Topics (话题大纲)**: 个人基本信息, 事件信息, 物品信息, 天气/环境, 日常交往/礼貌用语,
饮食, 出行/问路, 购物, 生病/探病, 休闲活动, 学习情况, 校园, 工作/职业, 中餐.

**Worksheet profile**:
- Sentences ≤ 8 characters, mostly 3–6. One clause only. Vocabulary #1–300 strictly (gloss
  anything beyond — at L1 there should be almost none).
- Sections B–D items: 4–6 per section, heavily visual formats (E1 bank-fill, E2 Q–A
  matching, P2 scramble with ≤6 tiles).
- Scaffolding: bilingual (Chinese + English) instructions everywhere; click-pinyin on every
  Chinese word; English glosses in keys expected. True/false and match formats preferred
  over typed input; typed input only in section E with pinyin-free character prompts.
- Question types: W1, R1, R2 (skip at L1 — use R1 only), P1, P2, P5, L1, L3(二选一),
  E1, E2, F1, F3, V1.
- Avoid: E3, E4, E6, F2, P3 (finding errors needs more language maturity), R3.

## HSK 2

**Exam structure (H20901)**: 听力 35题 (P1 picture true/false, P2 listen-pick picture,
P3 dialogue-match, P4 mini-passage MCQ) · 阅读 25题 (P1 sentence↔picture true/false,
P2 sentence-picture match, P3 Q–A matching, P4 word-bank fill) · ~55 min.

**Grammar spine**: verb/adjective reduplication, 离合词, 还是因为/虽然/所以 complex
sentences, 比 comparatives (basic), 着/过 aspects, 得/地, directional complements (basic),
结果补语, 要/快要…了, 还是…吧.

**Topics**: adds 外貌/生日, 原因/变化/状态, 出行感受, 家庭关系/活动, 传统习俗/节日, 姓氏文化.

**Worksheet profile**:
- Sentences ≤ 12 characters, 1–2 clauses. Vocabulary #1–551 (loose: +≤5%).
- Scaffold down: bilingual instructions; click-pinyin on all content; keys in English with
  Chinese examples.
- Question types: W1, W2, R1, R2, P1, P2, P3 (single obvious error), P4, P5, L1, L2, L3,
  E1, E2, F1, F3, V1, V2.
- D: prefer E1/E2 (official L2 formats).

## HSK 3

**Exam structure (H31001)**: 听力 40题 (P1 dialogue-match picture... P2 true/false,
P3 dialogues MCQ, P4 passage MCQ) · 阅读 30题 (P1 sentence-match, P2 fill with given words,
P3 Q–A matching, P4 cloze passage) · 书写 10题 (P1 word-order sentences, P2 write sentence
from given word) · ~90 min.

**Grammar spine**: 把字句1, 被动句1, 比较句2, 存现句3, 是…的1, 兼语句1, 可能补语1,
程度补语1, 越来越/除了…以外, 一边…一边, 反问句1, 先…再…, 只有…才….

**Topics**: adds 日常事务/业务办理, 交通规则, 探病/健康观念, 居住情况, 季节/气候/动植物,
环境状况, 现代生活/城市发展, 文艺活动, 体育比赛, 家庭教育, 地区差异.

**Worksheet profile**:
- Sentences ≤ 18 characters, ≤ 2 clauses. Dialogue 8–12 turns. Vocabulary #1–1000.
- Instructions bilingual; pinyin still behind click everywhere; English glosses in keys
  only for words > #1000.
- Question types: everything in the catalog except E4, E6, F4.
- D: E3 cloze (short, ~80字) or official L3 formats (word-order 书写 → P2 already covers;
  use E3 + one E2).
- This is the first level where P3 (error correction) and F2 (translation) shine — 把/被
  confusion, 是…的 vs 了, 都/也 placement are rich error sources.

## HSK 4

**Exam structure (H41001)**: 听力 45题 (P1 true/false ★-statements, P2 dialogue MCQ,
P3 passage MCQ) · 阅读 40题 (P1 fill with given words, P2 order sentence-pairs, P3 cloze
passage, P4 passage MCQ) · 书写 15题 (P1 word-order 10, P2 picture-sentence from given
words 5) · ~105 min.

**Grammar spine**: 把字句2, 被动句2(叫/让), 兼语句2, 比较句3, 反问句2, 双重否定,
无论/不管, 既然/即使/尽管, 反而/竟然/居然, 概数, 越来越…(L3 covered) — see inventory.

**Topics**: adds 成长过程, 房屋租赁, 职场交往, 科技/科普, 网络生活, 少数民族, 国粹,
人际交往礼仪, 名胜古迹.

**Worksheet profile**:
- Sentences ≤ 25 characters, 2 clauses common. Dialogue 10–14 turns. Vocabulary #1–2000.
- Instructions bilingual but shorter; keys in English; gloss only words > #2000.
- Question types: all except E4, E6, F4.
- D: E3 cloze (~120字) mirroring 阅读第三部分 + optionally E5 (书写P2 style, without
  pictures — describe the word set instead).
- L3 (true/false ★ statements) is a natural D-section format here since it mirrors
  HSK4 听力第一部分 — prefer it in C.

## HSK 5

**Exam structure (H51001)**: 听力 45题 (P1 short-passage MCQ ×20, P2 dialogues, P3
passages) · 阅读 45题 (P1 cloze 2 passages, P2 order 4 sentences into a paragraph,
P3 passage MCQ, P4 sentence-error correction 病句) · 书写 10题 (P1 word-order ×8,
P2 write 2 sentences from given words ×2) · ~125 min.

**Grammar spine**: 把字句3, 被动句3(给), 比较句4, 状态补语2, 趋向补语3(引申), 各类复句
加深 (哪怕…也, 一旦…就, 不但…反而), 固定格式 (从…来看, 由…组成, 与其说…), 语气副词
(毕竟、居然、简直、反而).

**Topics**: adds 心理健康, 交通/出行体验, 消费活动, 社区管理, 学习心得, 团队合作,
企业经营, 中外交流, 哲学思想/传统艺术, 投资理财(六), 新闻热点(六).

**Worksheet profile**:
- Sentences ≤ 35 characters; passages ~180字. Dialogue 10–14 turns. Vocabulary #1–3600.
- Instructions: Chinese primary, one-line English subtitle. Keys in English.
- Question types: all except E1, E2, E6 (E1/E2 are L1–2 formats).
- D: E3 cloze + E4 (summary choice) or P3 mirroring 病句 (HSK5 阅读第四部分).
- F: F1 + F2 (+ F4 optionally as a stretch item).

## HSK 6

**Exam structure (H61001)**: 听力 50题 (P1 pick statement matching the passage, P2
interview/dialogue MCQ, P3 passage MCQ) · 阅读 50题 (P1 cloze, P2 order 4 paragraphs,
P3 passage MCQ ×20, P4 pick sentence with a 语病 error) · 书写 1题 (write ≥400字 essay
condensing 3 given passages — worksheet adaptation: E6) · ~140 min.

**Grammar spine**: 类前缀/后缀 (超-, -化, -性), 把字句4, 凡是…都/除非…否则, 要么…要么,
虽…但…, 竟…(L5), 固定格式 (放着X不Y, 东一A西一A, X归X), 书面语 particles (所, 于, 因,
至于), 四字格 A这A那.

**Topics**: full adult range: 民生发展, 公益活动, 潮流风气, 古诗词/俗语, 朝代概况,
传统审美意象, 财务与消费, 投资理财, 新闻热点.

**Worksheet profile**:
- Passages up to 250字. Written-style (书面语) material encouraged alongside colloquial.
  Vocabulary #1–5400 (+≤5%).
- Instructions: Chinese only by default (English on request); keys English + Chinese
  rule statement.
- Question types: all except E1, E2, E5 (E5 acceptable occasionally).
- D: E4 + E6-essay-lite (~200字, note the real exam demands 400+ from source passages) or
  P3 mirroring 语病 questions.
- F: F4 mini-composition as the centerpiece of section E.

## Topic usage rules (all levels)

1. One topic context per worksheet (from the level's 话题大纲 list above), chosen in
   section C's dialogue and threaded through A/B/E.
2. Rotate topics across consecutive worksheets; check `progress-log.md` to avoid repeats.
3. L1–3 topics must stay concrete and everyday; L4 adds workplace/society; L5–6 may use
   abstract/cultural/news topics.
4. The topic only sets CONTEXT — every graded item still tests the grammar point.
